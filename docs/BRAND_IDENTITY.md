# MTI — الهوية البصرية الرسمية

## Brand Core
MTI = Precision Content Intelligence.
الشخصية: Intelligent, Technological, Minimal, Confident, Modern, Analytical.
الواجهة لازم تحس كتطبيق عالمي: هادئة، دقيقة، مساحات واضحة، حركة ناعمة، بدون ازدحام.

## الألوان
- Deep Navy `#0A192F` — التطبيق/الخلفية الأساسية.
- Rich Gold `#C5A059` — الهوية، CTA، المؤشرات الأساسية.
- Soft Cream `#FAF5F0` — بطاقات القراءة، النصوص الفاتحة، hero surfaces.
- Slate Gray `#3A4750` — النص الثانوي والحدود.
- Accent Green `#4CAF50` — success / confirmed / learning signals.
- Error Red `#E53E3E` — أخطاء حقيقية فقط، وليس لتلوين أي نتيجة سلبية تلقائياً.

## Typography
- Syne Bold/ExtraBold: brand, headings, metric displays.
- Inter: analytics, labels, data.
- Tajawal: Arabic UI fallback.

## Layout
- Desktop: left rail + sticky header + stage rail + content canvas.
- Mobile: compact stage rail, single-column cards, touch targets >= 44px.
- Border radius: 10–20px بحسب مستوى العنصر.
- Shadows: soft/deep only on elevated surfaces; no glowing neon UI.

## Navigation
المسار الأساسي الثابت:
**Analyze → Understand → Diagnose → Improve → Predict → Publish → Learn → Brain**

كل مرحلة يجب أن تكون قابلة للوصول مباشرة، مع active-state، smooth scroll، وحالة واضحة.
Navigation is a workspace control, not decoration.

## Intelligence UI Rules
- لا رقم بدون evidence.
- unavailable يظهر `—` أو `غير متاح`، وليس 0.
- measured / inferred / predicted / learned يجب أن تكون قابلة للتمييز بصرياً.
- Prediction لا يسمى retention فعلياً ما لم يدخل أداء المنصة الحقيقي.
- بعد النشر، Screenshot Insights يدخل كـ observed outcome ويرتبط بالـReel Version.
- Brain يقرأ Reel Room الحالي، التحليل، الذاكرة، المعرفة، والتعلم.

## Component Language
- Primary CTA: gold solid.
- Secondary: navy/outline.
- Data cards: elevated navy + subtle border.
- Hero insight card: soft cream.
- Progress: gold, animated only أثناء العمل.
- Charts: restrained gold/cream/green; avoid decorative chart noise.
- Empty/error/loading states must be designed, not browser-default alerts.

## Motion
- 160–240ms transitions for hover/focus.
- 300–500ms for section transitions.
- No infinite animation except loading/progress.
- Prefer transform/opacity over layout-changing animation.

## Product Principle
MTI ليس chatbot يكتب نصائح عامة. هو Content Intelligence workspace:
**Video evidence → Understanding → Diagnosis → Improvement → Prediction → Real outcome → Learning → Brain context.**
