# MTI — الهوية البصرية

## الألوان
- Deep Navy `#0A192F` — خلفية أساسية
- Rich Gold `#C5A059` — أساسي / أزرار CTA / تمييز
- Soft Cream `#FAF5F0` — نص فاتح / خلفيات ثانوية
- Slate Gray `#3A4750` — نص ثانوي / حدود
- Accent Green `#4CAF50` — نجاح / مؤشرات إيجابية

## الخطوط
- عناوين: Syne (Bold)
- نص عادي: Inter

## عناصر UI
- أزرار: Gold صلب (أساسي) + Outline (ثانوي)، حواف دائرية كاملة
- Navigation: شريط جانبي (Desktop) بأيقونات + خلفية Navy غامقة
- بطاقات بيانات: خلفية أغمق شوي من الأساسية، حواف دائرية، أرقام كبيرة بالـ Gold
- Progress bars: تدرج ذهبي
- Data viz: Donut chart + Line chart، بالألوان الثلاثة (Gold/Cream/Line)
- شخصية البراند: Premium, Intelligent, Technological, Minimal, Confident, Modern, Analytical
